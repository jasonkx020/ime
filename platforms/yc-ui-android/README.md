# yc-ui-android

Samsung One UI 6.x 键盘 UI（M1）：`ThemeTokens`、`SamsungKeyView`、`SamsungCandBar`、`SamsungToolbar`、`YcKeyboardPanel`。

设计规范：[docs/KEYBOARD_UI_DESIGN.md](../docs/KEYBOARD_UI_DESIGN.md)

默认拼音布局：美式完整 QWERTY（数字行 + 字母 + Shift/⌫ + 底栏），见 `Layout26Pinyin` / `layout_26_pinyin.json`。

由 `platforms/yc-shell-android` 通过 Gradle 模块依赖接入。
